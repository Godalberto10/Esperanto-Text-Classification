Esperanto Topic Classifier

Paste a text in Esperanto and the model estimates whether it is about Christianity, Islam or Judaism. Everything runs in your browser: a rule-based NLP library written from scratch lemmatizes the text, and a TF-IDF + logistic regression model trained on Esperanto Wikipedia classifies it.
